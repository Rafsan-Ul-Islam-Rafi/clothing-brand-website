Clothing Brand Website

A modern, responsive, and mobile-first storefront website design. Built with a focus on clean UI/UX, editorial visual storytelling, and smooth product browsing.

Features

- **Editorial Hero & Lookbook:** High-impact landing section showcasing seasonal collections and brand identity.
- **Product Catalog:** Clean grid layout for browsing apparel, filtering categories, and viewing item details.
- **Responsive Mobile-First UI:** Optimized for seamless navigation across desktop, tablet, and mobile viewports.
- **Interactive Cart / Quick View:** Smooth user interactions for exploring sizes, colors, and product highlights.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Styling & Layout:** CSS Grid, Flexbox, Custom Animations
- **Deployment:** GitHub Pages
